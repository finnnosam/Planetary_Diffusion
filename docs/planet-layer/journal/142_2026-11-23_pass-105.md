#### 1. The age hand-off (a defect, journal 141 §1 item 4)

What was wrong. The snapshot's `orogeny_age_myr` is t − last orogeny: 0 in an active belt, NaN where no orogeny was
recorded since the run began (old crust, ocean) or where no plate was. The plate layer erodes NaN as stable crust
(`surface.py`: since = inf). The landscape sampled the field with `nan_to_num` (NaN → 0) and then sent every age ≤ 0 to
10,000 Myr, so active belts eroded as old rock for the whole 30 Myr window, and a stencil mixing a finite age with a
missing one blended toward age 0 (younger than either corner).

The fix (Claude's design, under the delegation; changed from journal 141 §4's plan in one point):
- **Contract first** (`docs/contracts/plate-snapshots.md`, public): a finite value is valid and 0 is an active belt;
  NaN is the validity mask (no orogeny recorded, or no plate), eroded by the plate layer as stable crust; readers must
  not turn NaN into 0. Journal 141 planned a separate mask field beside the age. NaN already is that mask, the plate
  layer already reads it so, and a new snapshot field would change the plate outputs (and the borrow's field list)
  for no information. So the contract now states the meaning of NaN instead, and the plate layer is untouched.
- `coupling.erodibility_map(hist, p, t, rule)`: rule 'plate' (default) evaluates the plate layer's own law on the
  plate nodes (NaN old, finite 0 → 1) and samples the *erodibility* bilinearly, so a mixed stencil blends between its
  corners' erodibilities (bounded 0.15–1) and never blends ages across a missing value. Rule 'legacy' keeps the old
  defect, for replays only. `coupling.erodibility` maps NaN to stable. `PlateHistory.sample` takes an explicit `fill`
  (default 0 as before, for the fields where NaN carries no meaning; the age is no longer read through it).
- `build_forcing` no longer writes `orogeny_age_myr.npy`; `run_planet_landscape.run` computes the erodibility from the
  present snapshot every run (so a reused forcing folder cannot carry a stale rule), records the rule and the
  erodibility on the plate layer's present land in `stats.json`, and takes `--forcing` (reuse another run's forcing,
  read only) and `--age-rule`. A forcing folder built for another plate run is now refused instead of rebuilt in place
  (it would have overwritten the replay's "before").
- Tests (`tests/test_coupling.py`): an active patch (1.0; legacy 0.15), an old patch (500 Myr), a missing patch (0.15),
  a young patch (30 Myr), and a mixed stencil (young against missing never reads younger than 30 Myr; legacy does).
  5 of 5 pass in the cloud and in the device shell (from a copy).
- The plate layer does not read the field and no plate-layer file changed, so plate runs are unchanged by construction
  (no step identity test needed; `git diff --stat` touches `planet_landscape`, `scripts/run_planet_landscape.py`, the
  test and the contract only).

#### 3. The missing lithospheric-support update, measured (the review's item 2)

The landscape forces a continental parcel with the plate layer's tectonic thickening (a rock load it compensates
itself) and the change of dynamic topography less the sea's change. It has no channel for C, the change of the mantle
lithosphere's thermal support (`lithosphere.elevation_term` of the tectonothermal age). `support_omission.py` follows
the n = 217 nodes back 30 Myr through the Chain run's snapshots and reads C at both ends (air-loaded, nearest node) on
parcels continental throughout (`support_omission.txt`):

|---|---:|---|---|---|
| all | 1.000 | −9; −107 / −20 / +70 | 0.198 / 0.078 | 81 / 450 / 315 |
| land at 0 Myr | 0.727 | −22; −119 / −22 / +38 | 0.194 / 0.075 | 78 / 444 / 285 |
| land > 3 km at 0 Myr | 0.011 | +70; −532 / −3 / +849 | 0.705 / 0.455 | 352 / 3,055 / 306 |
| land, no thickening on the path | 0.083 | −16; −27 / −21 / 0 | 0.024 / 0.006 | 23 / 3 / 351 |
| land, thickened > 500 m | 0.256 | −63; −226 / −51 / +44 | 0.374 / 0.134 | 128 / 969 / 264 |
| land, thinned < −500 m | 0.139 | +37; −79 / 0 / +201 | 0.220 / 0.105 | 95 / 484 / 270 |

Reading. Over the landscape's window the omitted channel is about a fifth of the load channel and a quarter of the
dynamic one on land (mean |ΔC| 78 m), small where the crust did not thicken (cooling alone, −21 m median), and large
in belts: thickened land loses 63 m on average (to −226 m at p10) that the landscape never takes away, and land above
3 km moves by 352 m on average either way (collision thickening lowers it, foundering resets raise it; 46% beyond
±250 m). Its correlation with the closure gap (the plate layer's Δz minus the two channels, which also holds the plate
layer's own erosion) is weak (+0.19 on land), so it is not the main part of that gap. Conclusion: the omission matters
in belts and rifts, not in the interiors the shoreline question is about. Queued (not built): a C channel in the
landscape's surface forcing (the change of `elevation_term` along the path, as the dynamic channel). It is not built
now because the age fix's replay must read alone first, and because §0 item 1 comes before the landscape.

#### 4. The shoreline and lowland trace: question and reading rule (fixed before any run)

Built: `outputs/planet-calibration/precheck-p105-trace/trace_shore.py` (its docstring defines every measure). It wraps
one `PlateSim`'s `_world_from`, `_erode` and `_update_rasters` on the instance and reads a chain of surfaces per step:
`prev_end` → `composed_olddyn` (rotation and plate-to-world composition, old dynamic field: what the previous return
transfer left in the plate rasters shows here) → `composed` (this step's field) → `tectonics` (rift, crust flow,
subduction, volcanism, foundering, arcs) → `eroded` (erosion and deposition) → `transferred` (pelagic, basins turned
continental, the return transfer) → `end` (back-arc strips, events; `state()`). Side readings: `returned` (the plate
rasters read back at this step's rotation), `end_local` (local Airy in place of flexure), `end_prev_sea` (the previous
sea level). Each surface is an elevation with the sea re-solved; the probe restores the sea level after every extra
solve. **Check: traced = untraced, field by field, 5 of 5 steps** (n = 48, seed 1028, threads 1; `check-identity`).
Measures per surface: land; one-cell holes and islands; unique crossings per Mkm²; four-ring dry land and the low,
flat four-ring interior; low land (< 200 m) among land ≥ 300 km from water (graph distance) and that far land's share;
the drowned normal band and its entrants and exits; roughness of the surface, the crystalline crust and the sediment on
continental interiors; holes and islands made and destroyed against the previous surface, the made holes tallied by
marks set at `prev_end` (crystalline class, distance to the material continental edge, boundary history). The return
transfer directly: the share of continental plate nodes no world node read, and the rms of the increments they missed
against the applied ones. Modes from one warm state (cloud, seed 1028, threads 1, run to −20 Myr and pickled):
`default` (20 traced steps), `smoothed` (each plate's continental crust and sediment smoothed by 100 km, conservative,
then 20 traced steps), `null` (smoothed material, rigid rotation and composition only, nothing else, 20 steps) and
`null_raw` (the same on the unsmoothed material).

A prior suspect, written down before the run so the trace can refute it: the return transfer applies a step's
increments only to plate nodes some world node reads (`composition._update_rasters`, pass 2); the others miss that
step's erosion and deposition (the series already notes ~17% of continental sediment increments lost to nearest-node
sampling). A plate node that misses a deposit becomes a pit next to filled neighbours. The holes' contrast (−168 m of
sediment, −261 m of elevation, +0.4 m of field; journal 141 §1) fits that. The smoke run at n = 48 (meaningless
values, plumbing only) gave an unread continental share of 2.2%.

**Question.** Which operation of a plate-layer step first produces the excess one-cell holes and islands and the
excess land–water crossings, and which operation removes the inland low ground?

**Reading rule** (fixed now; read in pass 106 on `summary.txt` and the `trace-*.jsonl` files):
- R1, the null. If `null` grows one-cell features (holes + islands) or crossings over its 20 steps by more than 25% of
  the gap between `default`'s mean at `end` and `smoothed`'s start, the composition itself makes the roughness: the
  next arm is a conservative plate-to-world composition.
- R2, the creator. Per chain stage, the mean gross creation of one-cell features per step (holes made + islands made
  against the previous stage). The creator is the stage with the largest creation if it holds ≥ 40% of the chain's
  total creation in both `default` and `smoothed`. If the two modes disagree, or no stage reaches 40%, `smoothed`'s top
  stage decides (the regrowth from smooth material is the cleaner test) and `default`'s is reported. Map:
  `composed_olddyn` → rotation, composition and the previous return transfer; `composed` → the dynamic field's
  change; `tectonics` → the tectonic increments; `eroded` → erosion and deposition; `transferred` → pelagic rain,
  basin conversion, the transfer; `end` → back-arc and events.
- R3, fast or slow. If `smoothed` reaches ≥ 50% of `default`'s mean count of one-cell features at `end` within its 20
  steps, the roughness is remade every step and R2's creator is the arm. If not, it builds over the history: R2's
  creator still names the arm, but pass 106 first runs a longer smoothed trace (≥ 60 steps) and reads which marks the
  made holes carry before anything is built.
- R4, the transfer. If R2 names `composed_olddyn` and the unread continental share is ≥ 5% with the missed sediment rms
  ≥ 50% of the applied, the arm is a conservative return transfer (every plate node gets its increment). If R2 names
  `composed_olddyn` but these fail, the arm is the composition's resampling (R1's arm).
- R5, the lowland. The stage with the largest mean net loss of low far land (far_low_out − far_low_in) in both modes,
  and the stage that lowers the low, flat interior most, are reported beside R2. If it is R2's stage, one arm serves
  both. If not, the shoreline's arm goes first (§0 item 1 names the shoreline before the lowland) and the lowland's
  stage is queued as the next arm.
- The side readings (`end_local`, `end_prev_sea`) are reported, not ruled on: local Airy is a different model, not
  a switch-off of one operation.
- One seed (1028, cloud) is a mechanism read, not a terrain claim; nothing is adopted from it.
