**4. Why the passive lifespan fell.** The survival record's lifespan is standing passive edge over its ending rate.
Last 150 Myr, A → D: standing passive edge 58.9k → 58.9k km (the same), births 531 → 657 km/Myr, of them rifted (floor
< 25 Myr beside the new edge) 0.70 → 0.51: **rifted births 372 → 335 km/Myr, births beside old floor 159 → 322**. Ends
637 → 857 km/Myr, by subduction 0.32 → 0.41 of the ends (seed means). Arc crust that turns continental (≥ 20 km) on
an oceanic plate makes new continental edge beside old floor, which the record counts as passive birth; those edges
end at the next trench within tens of Myr. Earth's lifespan (Bradley 2008) is of rifted passive margins only. So the
fall is mostly the record counting arc-terrane edges, not shorter rifted margins (their births are 10% fewer, inside
the seeds' spread). Next for this score: read the record by birth type (output only; it changes `stats.json`, the
identity reference, so it goes with the next default-path change), not a model change.

T3's rise has the same likely cause: arc crust ≥ 20 km on the overriding plate types an intra-oceanic trench as
continental-side (continental side +5.8k km, intra-oceanic −2.8k). Not verified this pass (a probe on snapshots: the
continental-side trench's overriding crust by origin).
