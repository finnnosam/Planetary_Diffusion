# Planet layer: decision log

One line per thing that was decided: adopted, rejected, kept, or fixed. Newest at the bottom of each table. The
reasoning, the numbers and the rule that decided it are in the journal entry linked in the last column
(`journal/`, one file per pass, verbatim from the old plan doc). Current settings and scores: `STATE.md`.

Every sweep is in `outputs/planet-calibration/<sweep>/`, with its reviews in `<sweep>/reviews/`.

**Older rows are archived, unchanged:** 17–31 Oct in `decisions-archive-oct.md`, 1–7 Nov in
`decisions-archive-nov1.md` (moved 15 Nov), 8–11 Nov in `decisions-archive-nov2.md` (moved 16 Nov), 13–15 Nov in
`decisions-archive-nov3.md` (moved 20 Nov), 16–17 Nov in `decisions-archive-nov4.md` (moved 21 Nov), 18 Nov in
`decisions-archive-nov5.md` (moved 21 Nov, pass 102), 19 Nov in `decisions-archive-nov6.md` (moved 21 Nov, pass 103), 20 Nov in `decisions-archive-nov7.md` (moved 22 Nov, pass 104), 21 Nov in `decisions-archive-nov8.md` (moved 26 Nov, pass 107). Read them before re-proposing something; a later row here can supersede
an archived one. When this file passes ~35 KB, move its oldest rows to a new `decisions-archive-<period>.md` the same
way (each part must fit one read to be mirrored to the Project).

**How to add a row:** when a pass adopts, rejects, keeps or fixes something, add one row here in the same pass. Give
the parameter or setting, the outcome, the sweep (or "none"), one clause of reason, and the journal file.
