# Project map (planet layer work; layout as of 29 Oct 2026, phase B of the migration)

This is the `Planetary_Diffusion` repository (split from `Infinite_Diffusion` on 29 Oct 2026; records in
`docs/planet-layer/journal/60_2026-10-29_repo-split.md` and `61_2026-10-29_packages.md`). It has one installable
package per stage under `packages/` and no link to the original generator: `planet_grid.cube` and
`planet_meso.procedural` are copies of the generator's modules. The generator (`planet_diffusion`, Terrain Diffusion
on a sphere) stays in `E:\projects\Infinite_Diffusion`, is not installed here, and gets no planet work.

A quick orientation for a new chat. Read with `docs/planet-layer/STATE.md` (what is running, the model, the
scorecard, next steps), `CLAUDE.md` at the root (working rules; since 26 Nov, journal 149), `docs/planet-layer/gotchas.md`
(traps found so far), `docs/planet-parameter-audit.md` (which values
are measured, assumed or fitted) and `docs/planet-layer/decisions.md` (what was adopted or rejected). The history is
in `docs/planet-layer/journal/` (one file per pass); the old single plan doc `planet-layer-plan.md` (deleted 30 Oct) was `design-2026-10-17.md` + journal 01–58
(code comments and `.cmd` headers cite its passes: "Nth pass" = `journal/*_pass-NN.md`). The root `README.md` introduces this repository; the original generator's README is in `..\Infinite_Diffusion`.

## The chain

```
P  plate layer      planet_tectonics (sim.py)     cube n=217 (46 km), 1 Myr steps, 250 Myr from a supercontinent
        |  snapshots: docs/contracts/plate-snapshots.md
        v
L  landscape stage  planet_landscape (coupling +  cube n=868 (11.53 km), 50 kyr steps, last 30 Myr,
                    graph_landscape)              present-day geometry with parcel histories
        v
H  hand-off         docs/contracts/handoff-23km.md  exact area mean onto the meso's 23.04 km cells (scripts.planet_meso_check)
        v
M  meso             planet_meso (planet_tiled.py)  diffusion model 23 km -> 2.88 km, outputs/meso/detail-ft/step10000-passed.pt
```
Direction (user, 23 Oct): realism. Values come from Earth measurements or mechanism, never from fitting the planet's
output to a band; any system may be changed if it moves toward realism.
